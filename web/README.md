# Interfaz / Interface

**Español:** HTML, CSS y JavaScript originales de Nexo Chess 1.0, incrustados en el ejecutable. Para jugar, abre `NexoChess.exe`; no abras `index.html` directamente.

**English:** Original Nexo Chess 1.0 HTML, CSS, and JavaScript, embedded in the executable. To play, open `NexoChess.exe`; do not open `index.html` directly.
