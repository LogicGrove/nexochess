# Nexo Chess

[Español](README.md) | **English**

**One network. Two people. One game.**

Nexo Chess is a free, portable application for playing chess with another person on the same local network, such as your home Wi-Fi. Only the host computer runs the application; everyone else joins using a browser on a PC, phone, or tablet.

You do not need internet access, an account, or additional software. **Version 1.0 is for games between people, with no clock or AI opponent.**

## Download and play

**[Download Nexo Chess 1.0 for Windows](https://github.com/LogicGrove/nexochess/releases/tag/v1.0.0)** · 64-bit Windows 10/11.

1. Download `NexoChess-1.0.0-Windows-x64.zip` and extract its contents.
2. Open **`NexoChess.exe`**. Your browser will open.
3. Enter a nickname, create a table, and choose White or Black.
4. Share the **network address shown by the app** with the other person.
5. They open that address in their browser and join the same table. Keep the application running on the host computer.

If Windows asks for network access, allow Nexo Chess on your **private network**. Both devices must be connected to the same network.

## Features

- Multiple tables, color selection, and spectator access.
- Legal move markers, check, checkmate, stalemate, and common draw situations.
- Castling, en passant, and promotion to queen, rook, bishop, or knight.
- Move history and rewind to review positions without changing the game.
- Undo, restart, and agreed draws with the opponent's acceptance.
- **PGN** export, light and dark themes, board flipping, and a responsive layout.

**Games are kept only in memory and disappear when the program closes. Export a PGN if you want to keep them.**

## If the other player cannot connect

Use the address shown by your app, avoid guest Wi-Fi, and check the Windows permission for private networks. If you use a VPN, choose the address of your Wi-Fi or Ethernet adapter. Router port forwarding is not needed.
