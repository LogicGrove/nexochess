# Pruebas / Tests

**Español:** Pruebas de desarrollo originales. `frontend.test.cjs` usa Node y JSDOM 27; `native_smoke.py` comprueba el servidor Windows y lo apaga al terminar. No son necesarias para jugar. Consulta la [guía avanzada](../docs/README.advanced.md).

**English:** Original development tests. `frontend.test.cjs` uses Node and JSDOM 27; `native_smoke.py` checks the Windows server and shuts it down when finished. They are not needed to play. See the [advanced guide](../docs/README.advanced.en.md).
